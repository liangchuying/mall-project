# 商城系统功能规划

## 项目现状

基于 Spring Boot 3 + MySQL + MyBatis-Plus + JWT 的后端商城系统基础框架已完成搭建。

已实现的基础设施：
- Spring Boot 3.2.0 + MySQL 8.x + MyBatis-Plus 3.5.5
- JWT 身份认证配置
- MyBatis-Plus 分页、逻辑删除、自动填充
- 跨域配置
- 统一响应结果封装
- JWT 工具类

## 开发优先级建议

1. **P0 核心功能**：用户模块、商品模块、购物车、订单基础流程
2. **P1 重要功能**：支付模块、优惠券、评价
3. **P2 高级功能**：秒杀、拼团、数据统计
4. **P3 优化项**：缓存、消息队列、分布式锁
